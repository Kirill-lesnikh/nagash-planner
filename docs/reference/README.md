# Reference assets

Images gathered during research. They are for **reference only**. The shipped app should use icons extracted from the game (see [../data-model.md](../data-model.md#extraction-pipeline)).

| File | What | Source |
|---|---|---|
| `black-pyramid-full.jpg` | Full Black Pyramid tree, 7911×5703, every node visible. Use it for layout tracing. | [Wiki file page](https://totalwarwarhammer.fandom.com/wiki/File:The_Black_Pyramid_of_Nagash.jpg) |
| `black-pyramid-preview.jpg` | Same image, downscaled to 1600px | derived |
| `crop-start-area.jpg` | Start node, the first clusters and the two lowest gateways | derived |
| `crop-top-center.jpg` | Top-centre Nagash column and the Mortarch portrait nodes | derived |
| `icons/wh3_dlc29_*.png` | Undead Legions UI icons from the wiki: resource icons (sigils, Black Pyramid, Mortarchs) and **building-chain** icons. These are *not* the tree's node icons. | Wiki (`api.php?list=allimages&aiprefix=wh3_dlc29_nag`) |
